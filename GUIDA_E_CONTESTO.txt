1. COS'E' PRIVATEVIEWER
================================================================================
PrivateViewer e' una suite desktop autonoma, invisibile a catture dello schermo e 
progettata per proteggere appunti, documenti PDF, pagine web e web app (come 
ChatGPT o WhatsApp Web) dalla registrazione video o da condivisioni schermo.

Quando e' attiva, la finestra e' perfettamente visibile e utilizzabile da chi e' 
seduto davanti al monitor fisico, ma risulta completamente INVISIBILE a:
- Screenshot di sistema (Strumento di cattura, Win + Shift + S, Stamp)
- Software di registrazione dello schermo (OBS Studio, Camtasia, ecc.)
- Software di condivisione dello schermo (Discord, Microsoft Teams, Zoom, Meet)
- Motori di cattura desktop standard (Desktop Duplication API / DWM)

2. GUIDA ALL'USO (FUNZIONALITA' E CONTROLLI AVANZATI)
================================================================================
- AVVIO:
  Fai doppio clic su "PrivateViewer.exe".

- BARRA DEL TITOLO NERA NATIVA (DARK TITLE BAR):
  La barra in alto con il titolo e i pulsanti di riduzione, ingrandimento e 
  chiusura [X] e' ora completamente nera con scritte bianche, perfettamente 
  integrata con il tema scuro dell'applicazione.

- MODALITA' FOCUS / NASCONDI MENU (ZEN MODE):
  * Clicca su "▲ Nascondi Menu" oppure usa la scorciatoia da tastiera [Ctrl + M] 
    (o il tasto [F1]) per nascondere all'istante le barre dei comandi superiori 
    e visualizzare SOLO le schede e le pagine web.
  * Quando i menu sono nascosti, una sottile barra superiore mostra il tasto 
    "▼ Mostra Menu (Ctrl+M)" per ripristinare i menu in qualsiasi momento.
  * Premendo [F11] si attiva la modalita' a Schermo Intero totale senza bordi.

- MODALITA' STEALTH (INVISIBILE NELLA BARRA DELLE APPLICAZIONI):
  Di default, l'applicazione NON compare nella barra delle applicazioni in basso 
  ("👻 Stealth").
  L'icona dello scudo nella System Tray permette di ripristinare la finestra con 
  un clic sinistro o di aprire il menu contestuale con il clic destro.

- SISTEMA A SCHEDE MULTIPLE (MULTI-TAB BROWSER):
  * Clicca su "➕ Scheda" oppure usa [Ctrl + T] per una nuova scheda.
  * Chiudi la scheda corrente con [✕] o con [Ctrl + W].
  * Naviga tra le schede con [Ctrl + Tab].
  * Barra URL dinamica al 100% che si adatta a qualsiasi dimensione della finestra.

- VISUALIZZATORE PDF E DOCUMENTI:
  * Clicca su "📂 File / PDF" per selezionare qualsiasi documento PDF o immagine.
  * Oppure trascina semplicemente il file PDF dentro la finestra (Drag-and-Drop).

- MENU WEB APPS RAPIDE:
  Pulsanti diretti a 1 clic per ChatGPT, Gemini, WhatsApp Web e menu a tendina 
  per Telegram Web, Wikipedia, Calcolatrice Scientifica e Google Traduttore.

- BOSS KEY RAPIDO GLOBALE (Tasto ESC):
  Premendo [ESC] la finestra scompare all'istante nascondendosi nell'area 
  di notifica di Windows (System Tray).

3. CONTESTO TECNICO (COME FUNZIONA SOTTO IL COFANO)
================================================================================
A partire da Windows 10 (versione 2004) e su Windows 11, Microsoft ha introdotto 
il flag Win32:

    SetWindowDisplayAffinity(HWND hWnd, DWORD dwAffinity);
    // WDA_EXCLUDEFROMCAPTURE = 0x00000011

Inoltre, per la barra del titolo scura viene utilizzata l'API DWM nativa:

    DwmSetWindowAttribute(hWnd, DWMWA_USE_IMMERSIVE_DARK_MODE, ref 1, 4);
    DwmSetWindowAttribute(hWnd, DWMWA_CAPTION_COLOR, ref 0x00141414, 4);

================================================================================

5. CASI D'USO CORRETTI E CONSIGLIATI
================================================================================
Presentazioni in call (Teams/Meet/Zoom), streaming OBS senza secondo monitor, 
consultazione protetta di documenti e appunti durante condivisioni desktop.

================================================================================
6. LIMITAZIONI IMPORTANTI E CONTESTO DI SICUREZZA (es. VEYON / SCUOLE)
================================================================================
Il software non maschera i processi nel Task Manager/Veyon Process List ne' il 
movimento del cursore del mouse. Non utilizzare per eludere controlli scolastici.
